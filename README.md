# Task Manager API

A simple REST API built using Flask.

## Features
- Get all tasks
- Add a task
- Update a task
- Delete a task

## Tech Stack
- Python
- Flask

## Run

pip install -r requirements.txt  
python app.py

## API Routes

GET /tasks  
POST /tasks  
PUT /tasks/<id>  
DELETE /tasks/<id>

- Persistent storage using SQLite database
